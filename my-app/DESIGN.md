> 개정된 Y2K 레트로 OS 스타일 기준입니다. 이전(그라디언트 + 안상수체) 디자인은 폐기되었습니다.

## 4. 레이아웃 공통 수치

| 항목 | 값 |
|---|---|
| 기준 프레임 | 402×874 |
| 헤더 높이 | 69 (하단 선 포함) |
| 하단 탭바 높이 | 80 + 하단 안전 영역 |
| 기본 카드 반경 | 10 |
| 화면 좌우 여백 | 16 |

**작은 화면(예: iPhone SE) 대응 규칙**
- **기준 기기(402×874, iPhone 16 계열)와 그보다 큰 화면은 Figma 설계 그대로입니다.** 아래 규칙은 모두 기준보다 짧거나 좁은 화면에서만 적용됩니다 (글자·그래픽 배율은 0.96 이상이면 1, 여백·캐릭터 축소는 본문 높이가 기준 `REF_BODY_H`=629 이상이면 적용 안 함).
- **글자는 앱 전체가 같은 배율**로 줄어듭니다 (`constants/typography.ts`의 `fs()`). 모든 글자에 같은 비율을 곱하므로 3장의 위계(제목 > 본문 > 보조)의 비율은 그대로이고, 화면마다 다르게 줄어드는 일이 없습니다.
  - 배율 `UI_SCALE` = 화면 높이·폭 중 더 작은 쪽 기준(402×874 대비), 일반적인 큰 화면은 1(그대로), 가장 작아도 0.85까지만. 10 이하의 작은 글자는 더 줄이지 않습니다.
  - 새 글자 스타일을 만들 때는 `fontSize: fs(n)`, `lineHeight: fs(n)`으로 씁니다. 예외: 도감 카드의 세부 설명(태그라인·소개)은 줄이지 않습니다.
- **카드·버튼·화살표 같은 그래픽 크기**는 `ui(n)`으로 같은 배율을 곱합니다 (도감 카드·더 알아보기, 캘린더 날짜 칸 등).
- **여백과 캐릭터**는 남는 높이에 따라 추가로 줄입니다 (`utils/layout.ts`의 `compactFactor`).
- 그래도 모자란 아주 짧은 화면에서만 `components/common/FitToScreen.tsx`로 화면 전체를 마지막 수단으로 축소합니다 (하한 0.55).
- 적용 화면: 글자는 앱 전체, 여백·캐릭터 축소는 홈·Record 캘린더 탭·도감 카드 덱. 채팅·앨범·도감 상세는 원래 스크롤 화면이라 글자 배율만 적용됩니다.

### 연속 관리 (`app/streak.tsx`)
Figma 55:16 기준. 위에서 아래로: 캐릭터(190×283) → 간격 50 → 월~일 7칸(완료 라임 ✓ / 지난 미기록 회색 ✕ / 그 외 빈 원) → 간격 50
→ `N일 연속 관리 중!`(Heavy 28) → `{닉네임}와 함께한지 N일째`(입양일 = 1일째, 15). 이 묶음은 버튼 위 영역의 세로 가운데에 놓고, 작은 화면에서는 캐릭터와 간격만 줄입니다.
하단 라임 버튼은 채팅의 `홈으로 돌아가기` 버튼과 같은 크기·위치(좌우 16, 높이 48)이고, 문구는 `constants/streakMessages.ts`의 7가지 중 화면이 열릴 때마다 무작위로 나옵니다.
등장 연출: 배치가 끝나면 바로 화면 위쪽(높이의 약 33%) 가운데에서 컨페티(노랑 `#FFD84A`·분홍 `#F296A2`·하늘색 `#8FD3FF`, 260개)가 위로 터져 오른 뒤 중력·공기저항으로 팔랑이며 떨어지고(캐릭터·글자 뒤 층), 같은 때 오늘 칸의 체크 원이 44px 튀어올랐다가 통통 튀며 제자리에 정렬. 진동은 터질 때 강→중, 체크 착지 때 성공 진동. '동작 줄이기' 설정이면 컨페티 생략. `N일 연속 관리 중!` 글자는 왼쪽부터 70ms 간격으로 10px씩 통통 뛰어오르고, 약 2.6초마다 반복(`HoppingText`, 첫 바퀴는 0.9초 뒤).

## 7. 컴포넌트 작성 규칙

- 색상은 `COLORS`, 폰트는 `FONTS` 상수 사용 (하드코딩은 Figma 고유 값일 때만)
- 새 화면은 헤더에 `TopAppBar`, 하단에 필요 시 `BottomNavBar`를 사용
- 월페이퍼 화면은 `<Wallpaper />` 컴포넌트 사용
- 컴포넌트 파일명은 PascalCase, StyleSheet는 파일 하단, props 타입은 상단 interface
- 아이콘은 코드로 그린 SVG(`Icons.tsx`, `ActionIconButton.tsx`)를 사용. 아이콘 파일 에셋은 따로 두지 않음
- 이모지는 UI 버튼·안내 문구에 쓰지 않음

## 화분 얼굴 종류 (`constants/character.ts`의 `FACE_SETS`)
- 표정(`Expression`)은 얼굴 종류와 같은 6가지뿐이다. 이미지는 `scripts/build_faces.py`가 `characters/_source/`의 원본 레이어로 `face_v2/`에 만든다 (식물별 위치 `dy`·눈 배율 `eye`는 스크립트 상단 `ADJUST`).
- `default` 기본(눈 깜빡임) / `smile` 웃음(바질만, task 완료) / `neutral` 무표정 / `tear` 눈물(3프레임) / `cry` 더 슬픈 눈물(메리골드만) / `surprise` 놀람(3프레임, 바질만)
- 바질 무표정 = 우는 입·눈썹 + 기본 눈. 없는 얼굴은 `cry → tear`, 나머지는 `default`로 대체 (smile·surprise는 바질만 있어 다른 식물은 기본).
- 상황별 표정 (`constants/expressions.ts`): 하루 관리 건너뜀(1일 초과) 무표정 → 2일 눈물 → 3일 이상 더 슬픈 눈물 / 채팅 열기·사진 요청 놀람 / task 완료 웃음 / 그 외 기본. 채팅 중 일시 표정은 놀람(첫 기록 시작)과 기본 복귀뿐.
- 애니메이션은 홈에서만 재생하고 다른 화면은 정지 프레임을 보여준다.
