> 피그마 디자인 파일: https://www.figma.com/design/jXKweeUqBSBAFwVjlJaJLq/RootMate-my-app
>
> 개정된 Y2K 레트로 OS 스타일 기준입니다. 이전(그라디언트 + 안상수체) 디자인은 폐기되었습니다.

## 3. 타이포그래피

폰트는 **SUITE** 하나만 사용합니다(정적 4종) (`assets/fonts/SUITE-*.ttf`, `app/_layout.tsx`에서 등록).

```typescript
// constants/typography.ts
FONTS = { regular, medium, bold, heavy }  // 'SUITE-Regular' … 'SUITE-Heavy' (4종: 400 / 500 / 700 / 900)
```

| 용도 | 폰트 | 크기 / 줄높이 | 비고 |
|---|---|---|---|
| 헤더 로고 `Rootmate` | Bold | 20 / 28 | 자간 0.9, 흰색 1px 그림자, `#052e16` |
| 헤더 배지 `D+N` | Bold | 15 / 16.5 | |
| 날짜 | Bold | 15 / 20 | `#286905` |
| 홈 대사 | Bold | 20 / 40 | `#064e3b`, 한 줄 |
| 하단 탭 라벨 | Bold | 13 / 15 | 자간 -0.25 |
| 상단 탭 (캘린더/앨범) | Bold | 22 / 45 | 활성 `#14532d`, 비활성 `#c5c7c0` |
| 도감 상세 탭 | Bold(활성) / Bold | 16 / 45 | 비활성 `#7f7f7f` (Record 탭보다 한 단계 아래 위계) |
| 말풍선 본문·선택지 | **Medium** | 15 / 23 | 자간 -0.275, `#424343`. Figma Bold(700)가 기기에서 더 굵게 보여 Medium 사용 |
| 식물 이름(채팅) | Bold | 16 / 16 | `#064e3b` (줄 높이는 글자 크기 이상) |
| 입력창 글자 (채팅·설정) | Medium | 15 / 23 | 온보딩 입력창은 큰 입력이라 20 Bold로 따로 |
| 도감 카드 이름(앞·뒷면) | Bold | 18 / 24 | 기본 글자색 `#052e16`, 가운데 정렬 |
| 도감 카드 뒷면 부제 | Medium | 13 / 18 | 기본 글자색 `#052e16`(이름과 같음), 가운데 정렬 |
| 도감 카드 뒷면 설명 | Medium | 11 / 18 | 기본 글자색 `#052e16`, 왼쪽 정렬 |
| 도감 카드 `No.` / 재배 기간 라벨·값 | Heavy / Medium·Bold | 10 / 10·11 | 식물별 글자색 (카드 글자는 `fs()`를 쓰지 않음) |
| 도감 상세 카드 제목 / 본문 | Medium | 15 / 23, 13 / 23 | 제목은 7단계 중 14가 없어져 15(본문 13과 두 단계 차 유지). 선택 내용(`extra`): 점선 구분 + 라임 알약 `선택`(Bold 12) + 소제목(Bold 13) |

**글자 크기 7단계** (`constants/typography.ts`의 `FONT_SIZE`, 새 글자는 여기서만 고름)

| 이름 | 크기 | 주로 쓰는 곳 |
|---|---|---|
| caption | 12 | 보조 설명, 상세 선택 알약 |
| body | 13 | 본문, 라벨, 팝업 설명, 하단 탭 라벨 |
| bodyL | 15 | 말풍선, 날짜, 부제, 입력창(채팅·설정), 상세 카드 제목 |
| label | 16 | 버튼, 강조 라벨, 채팅 식물 이름 |
| title | 18 | 팝업·시트 제목, 캘린더 요일 |
| heading | 22 | 탭, 상세 이름, 월 제목, 온보딩 식물 이름, 시간 선택 |
| display | 28 | 온보딩·연속 관리 큰 제목 |

정리하면서 14는 13으로, 17은 18로, 24는 22로 옮겼습니다(도감 상세 카드 제목만 14 → 15). **단계에 넣지 않는 예외**: 도감 카드 안 글자(10·11·12·13, `fs()` 미사용), 헤더 로고·홈 대사·기록 제목·온보딩 입력창의 20.

> 굵기 규칙: 굵기는 Regular / Medium / Bold / Heavy 4종만 씁니다. 제목·날짜·탭 라벨은 Bold, 말풍선·카드 본문처럼 Figma가 Bold(700)로 지정한 긴 글은 Medium으로 렌더링합니다 (ExtraBold·SemiBold·Light 3종은 사용하지 않아 제거).

## 4. 레이아웃 공통 수치

| 항목 | 값 |
|---|---|
| 기준 프레임 | 402×874 |
| 헤더 높이 | 69 (하단 선 포함) |
| 하단 탭바 높이 | 80 + 하단 안전 영역 |
| 기본 카드 반경 | 10 |
| 화면 좌우 여백 | 16 |

**작은 화면(예: iPhone SE) 대응 규칙**
- **기준 기기(402×874, iPhone 16 계열)와 그보다 큰 화면은 Figma 설계 그대로입니다.** 아래 규칙은 모두 기준보다 짧거나 좁은 화면에서만 적용됩니다 (글자·그래픽 배율은 0.96 이상이면 1, 여백·캐릭터 축소는 본문 높이가 기준 `REF_BODY_H`=629 이상이면 적용 안 함).
- **글자는 앱 전체가 같은 배율**로 줄어듭니다 (`constants/typography.ts`의 `fs()`). 모든 글자에 같은 비율을 곱하므로 3장의 위계(제목 > 본문 > 보조)의 비율은 그대로이고, 화면마다 다르게 줄어드는 일이 없습니다.
  - 배율 `UI_SCALE` = 화면 높이·폭 중 더 작은 쪽 기준(402×874 대비), 일반적인 큰 화면은 1(그대로), 가장 작아도 0.85까지만. 10 이하의 작은 글자는 더 줄이지 않습니다.
  - 새 글자 스타일을 만들 때는 `fontSize: fs(n)`, 줄 높이는 `lineHeight: lh(n)`(글자 크기별 기본 줄 높이 표 `LINE_HEIGHT`, 글자 크기의 약 1.5배: 12→18, 13→20, 14→21, 15→23, 16→24, 18→27 …)으로 씁니다. 한 줄짜리 제목은 표보다 작게 둘 수 있지만 글자 크기보다 작게는 두지 않습니다. 폰트 이름은 `'SUITE-Bold'` 같은 문자열 대신 `FONTS.bold`를 씁니다. 예외: 도감 카드의 세부 설명(태그라인·소개)은 줄이지 않습니다.
- **카드·버튼·화살표 같은 그래픽 크기**는 `ui(n)`으로 같은 배율을 곱합니다 (도감 카드·더 알아보기, 캘린더 날짜 칸 등).
- **여백과 캐릭터**는 남는 높이에 따라 추가로 줄입니다 (`utils/layout.ts`의 `compactFactor`).
- 그래도 모자란 아주 짧은 화면에서만 `components/common/FitToScreen.tsx`로 화면 전체를 마지막 수단으로 축소합니다 (하한 0.55).
- 적용 화면: 글자는 앱 전체, 여백·캐릭터 축소는 홈·Record 캘린더 탭·도감 카드 덱. 채팅·앨범·도감 상세는 원래 스크롤 화면이라 글자 배율만 적용됩니다.

- 색상은 `COLORS`, 폰트는 `FONTS` 상수 사용 (하드코딩은 Figma 고유 값일 때만). 새로 쓰는 어두운 글자·테두리·빨강은 위 토큰(`borderDark`, `redStrong`, `textBubble`, `textInk` 등)을 쓰고 새 hex를 만들지 않는다. 아이콘 색 팔레트(주황 `#FF8E47`·파랑 `#14B5EB`·분홍 `#FF5C8D`·초록 `#38D76D` 등)는 `ActionIconButton`·`PlantDetailView`에 따로 정의돼 있다

- 월페이퍼 화면은 `<Wallpaper />` 컴포넌트 사용
- 컴포넌트 파일명은 PascalCase, StyleSheet는 파일 하단, props 타입은 상단 interface

- 이모지는 UI 버튼·안내 문구에 쓰지 않음

## 화분 얼굴 종류 (`constants/character.ts`의 `FACE_SETS`)
- 표정(`Expression`)은 얼굴 종류와 같은 9가지뿐이다. 이미지는 `scripts/build_faces.py`가 `characters/_source/{식물}/{표정 폴더}`의 원본 레이어로 `face_v2/`에 만든다(출력: `face_v2/{식물}/layers`·`overlays`, 효과는 `face_v2/fx`)(폴더 구조: 식물 → 기본·무표정·눈물·놀람·오열·윙크하트·음표, 공통 이미지는 `공통/`) (식물별 위치 `dy`·눈 배율 `eye`는 스크립트 상단 `ADJUST`).
- `default` 기본(눈 깜빡임, 바질은 기본 얼굴이 곧 웃음이라 `smile`은 기본으로 대체) / `neutral` 무표정 / `tear` 눈물(3프레임) / `cry` 더 슬픈 눈물(메리골드만) / `surprise` 놀람(입 고정 + 큰 눈, 바질만) / `wink` 윙크(오른쪽 눈 뜸·반쯤·윙크, 터치 반응) / `happy` 웃는 눈 ^^(터치 반응) / `sleep` 자는 얼굴(밤 12시~새벽 6시, 웃는 눈 ^^을 위아래로 뒤집은 감은 눈 ∪∪, 눈썹·볼·입은 happy와 같고 깜빡이지 않음)
- 바질 무표정 = 우는 입·눈썹 + 기본 눈. 없는 얼굴은 `cry → tear`, 나머지는 `default`로 대체 (surprise는 바질만 있어 다른 식물은 기본).
- **터치 반응 효과 이미지**(`face_v2/fx/`, 846×1254 캔버스 정렬): 윙크 하트 3프레임·음표 3프레임(식물별), 물방울 3프레임(`fx_drop_*`, 식물 공통), 자는 Z 3프레임(`fx_z_*`, 식물 공통, 색은 앱의 검정에 가까운 `textInk` `#191c1b`: 10단위 칸 Z가 작은 z → 둘 → 큰 Z 둘로 올라가고 빈 화면을 거쳐 반복). `PlantCharacter`의 `effect`로 얼굴 위에 한 장씩 올림. 사진으로 만든 캐릭터에서는 `CANVAS_FACE_CENTER`로 얼굴 위치에 맞춰 올림.
- 상황별 표정 (`constants/expressions.ts`): 하루 관리 건너뜀(1일 초과) 무표정 → 2일 눈물 → 3일 이상 더 슬픈 눈물 / 채팅 열기·사진 요청 놀람 / task 완료 웃음 / 그 외 기본. **밤 12시~새벽 6시(`hour < 6`)는 다른 상황보다 우선해 자는 얼굴**이고 Z가 계속 올라온다(탭·문지르기·길게 누르기 반응은 그대로 되고 끝나면 다시 자는 모습으로 돌아감). 자는 표정은 일별 기록용 `day_look`에는 저장하지 않는다. 채팅 중 일시 표정은 놀람(첫 기록 시작)과 기본 복귀뿐.
- 애니메이션은 홈에서만 재생하고 다른 화면은 정지 프레임을 보여준다.
