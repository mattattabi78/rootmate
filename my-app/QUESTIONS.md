# QUESTIONS.md — 마음 건강 질문 리스트

> 이 문서는 `constants/questions.ts`의 현재 내용을 그대로 옮긴 것입니다. 질문을 바꿀 때는 `questions.ts`를 수정하고 이 문서를 맞춰 주세요.
> 질문 선택 로직은 `services/api/questionPool.ts`에 있습니다.

---

## 질문 운영 방식

KST(한국 시간) 기준 날짜로 아래 순서대로 판단하며, 먼저 해당하는 규칙이 적용됩니다.

| 우선순위 | 조건 | 사용하는 질문 |
|---|---|---|
| 1 | 1월 1일 | `NEW_YEAR_QUESTION` (고정) |
| 2 | 12월 31일 | `YEAR_END_QUESTION` (고정) |
| 3 | 매월 1일 | `MONTHLY_START_QUESTION` (고정) |
| 4 | 매월 말일 | `MONTHLY_END_QUESTION` (고정) |
| 5 | 일요일 | `SUNDAY_DEEP_QUESTIONS` (29개) — 심화 질문 인덱스 순서대로 순환 |
| 6 | 토요일 | `WEEKEND_DAILY_QUESTIONS` (5개) — 월별 고정 셔플 순서로 날짜마다 하나씩 |
| 7 | 월~금 | `DAILY_QUESTIONS` (활성 47개) — 월별 고정 셔플 순서로 날짜마다 하나씩 |
| 별도 | 오랫동안 접속하지 않고 복귀 | `LONG_BREAK_QUESTIONS` (4개) — 날짜(일)를 개수로 나눈 나머지로 선택 |

- **월별 고정 셔플**: `연도×100+월`을 시드로 질문 목록을 섞어, 같은 달에는 항상 같은 순서가 됩니다. 선택 위치는 `(일 − 2) % 질문 수`입니다(1일과 말일은 고정 질문이라 2일부터 시작).
- **닉네임 치환**: 질문 안의 `{plantNickname}`은 식물 닉네임으로 바뀝니다 (현재 질문 목록에는 해당 표기가 없음).
- 평일 질문 목록에서 주석 처리된 질문은 사용되지 않습니다.

## 질문 설계 원칙

1. **식집사 정체성 유지**: 마음 건강이라는 단어를 직접 쓰지 않고, 식물 이야기나 일상 언어로 묻습니다.
2. **강요하지 않음**: 답하지 않아도 기록에 빈칸으로 남고 페널티가 없습니다.
3. **짧게 답해도 됨**: 한 단어, 이모지도 괜찮습니다.
4. **점진적 깊이**: 평일은 가벼운 안부와 오늘 하루, 일요일은 자신의 패턴을 돌아보는 심화 질문을 둡니다.
5. **닉네임 치환**: `{plantNickname}`이 있으면 식물 닉네임으로 바뀌어 개인화됩니다.
